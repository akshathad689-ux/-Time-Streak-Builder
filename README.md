# ⏱️ Time Streak Builder

A VS Code extension designed to help developers stay consistent with their daily coding practice by tracking the time they actually spend coding.

## 💡 Why I Built This

I wanted a simple way to track my daily C programming practice.

I didn't want a fixed Pomodoro timer. I wanted to start a timer when I begin practicing and let it run for as long as I actually practice.

So, I decided to build my own VS Code extension.

## ✨ Features

* ⏱️ Real-time practice time tracking
* 🔥 Daily practice streak
* 📅 Daily practice history
* 📊 Total practice time
* 📈 Days practiced
* ▶️ Start practice timer
* ⏸️ Pause practice timer
* 🔄 Reset timer
* 💻 Works directly inside VS Code
* 📴 Designed to work offline

## 🛠️ Technologies Used

* TypeScript
* Visual Studio Code Extension API
* VS Code Extension Development

## 📸 Dashboard

The Time Streak Dashboard displays:

* Days Practiced
* Total Practice Time

## 🚀 Getting Started

### Requirements

* Visual Studio Code
* Node.js
* npm

### Run the Extension

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:

```bash
npm install
```

5. Press `Ctrl + Shift + P`.
6. Select **Debug: Start Debugging**.
7. A new Extension Development Host window will open.
8. Open the **Time Streak Dashboard**.
